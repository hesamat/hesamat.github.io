CoursebookMD

CoursebookMD lets me teach from the same Markdown chapters that become a searchable coursebook students can revisit. Its focused lecture view keeps the material readable in class, while code, math, and diagrams stay together in the source.

Built for my COMP 1510 Programming Methods course.

SlideMD

SlideMD supports technical teaching with code, math, and diagrams alongside the explanation. It can import existing PPTX decks, while a separate presenter window supports teaching in class; offline builds and PDF export make the material usable outside the presentation too.

Built for my COMP 7855 Software Systems course.
