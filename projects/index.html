CoursebookMD

CoursebookMD is my attempt to build a better way of creating and teaching from course material: one connected Markdown coursebook that students can read, explore, and revisit, rather than a collection of slides. The same source supports my teaching and becomes the reference material students keep after class.

Built for my COMP 15010 Introduction to Programming Methods in Python course.

SlideMD

SlideMD supports technical teaching with code, math, and diagrams alongside the explanation. It can import existing PPTX decks, while a separate presenter window supports teaching in class; offline builds and PDF export make the material usable outside the presentation too.

Built for my COMP 7855 Software Systems course.
